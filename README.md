# Online Sales Analysis

## Descriere

Acest proiect este o aplicație Python simplă pentru gestionarea produselor și simularea unui coș de cumpărături într-un magazin online.

Proiectul a fost realizat pentru exersarea programării orientate pe obiecte (OOP) și a sistemului de versionare Git.

## Structura proiectului

- `product.py` – definește clasa Product.
- `product_manager.py` – gestionează produsele și inventarul.
- `cart.py` – gestionează coșul de cumpărături.
- `main.py` – punctul principal de pornire al aplicației.
- `config.json` – fișier local de configurare, ignorat de Git.
- `.gitignore` – stabilește fișierele care nu trebuie încărcate pe GitHub.

## Funcționalități

- Crearea produselor cu nume, preț și cantitate.
- Actualizarea cantității unui produs.
- Adăugarea și ștergerea produselor din inventar.
- Afișarea produselor.
- Calcularea valorii inventarului.
- Adăugarea aleatorie a trei produse în coș.
- Afișarea conținutului coșului.
- Calcularea valorii totale a coșului.

## Tehnologii utilizate

- Python
- Git
- GitHub

## Rulare

Pentru a porni aplicația, execută în terminal:

```bash
python main.py
```
